# Security Tools

## Overview

Security tools help analysts collect evidence, analyze systems and networks, detect suspicious activity, and investigate security incidents.

## Wireshark

Wireshark is a network protocol analyzer.

SOC analysts can use it to inspect network traffic and investigate:

- Suspicious connections
- DNS requests
- TCP communication
- Unusual protocols
- Potential malicious traffic

## Nmap

Nmap is a network discovery and security auditing tool.

It can help identify:

- Hosts
- Open ports
- Running services
- Network exposure

## Splunk

Splunk can collect, search, and analyze machine-generated data.

SOC analysts can use it to:

- Search logs
- Investigate alerts
- Correlate events
- Build dashboards
- Analyze security activity

## Kali Linux

Kali Linux is a Linux distribution containing many security-related tools.

It can be useful for cybersecurity labs and security testing.

## PowerShell

PowerShell is Microsoft's command-line shell and scripting environment.

SOC analysts may investigate PowerShell activity because attackers can abuse it for:

- Command execution
- System discovery
- Downloading files
- Persistence
- Lateral movement

## Bash

Bash is a common Linux shell.

It can be used to automate repetitive security tasks such as:

- Searching logs
- Extracting IP addresses
- Filtering events
- Processing security data

## Key Takeaway

Understanding security tools is important, but knowing **when and why to use each tool during an investigation** is more important than simply knowing the commands.
