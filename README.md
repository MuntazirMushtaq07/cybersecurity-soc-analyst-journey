## Lab Philosophy

All attack simulations and security testing documented in this repository are performed in **controlled lab environments**.

The purpose is to understand how attacks generate telemetry and how a SOC analyst can:

**Detect → Investigate → Contain → Eradicate → Recover → Learn**

No real-world systems are intentionally targeted.
